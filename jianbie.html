一、这 40 分钟怎么花目标不是「会做」，是「看到题目 10 秒内报出第一个试剂」

  1. 0–12min：过一遍下面的「试剂速记表」，只记 左列（被检物）→ 试剂 → 现象 三件套。
  2. 12–30min：10 道真题原型，先自己口述第一试剂，再展开答案对。对不上就回表格找那一行。
  3. 30–40min：把「易错与陷阱」看一遍，然后在纸上默写 5 条最常用的：Lucas / Hinsberg / 溴水 / FeCl₃ / NaHCO₃。
判断标准：随便报一组物质（如「苯酚、苯乙酮、苯甲酸」），你能立刻说出「先 NaHCO₃ 挑酸 → FeCl₃ 挑酚 → 剩下的酮」。答不出就再刷一轮表格。

三、真题原型 10 题2021–2026 真题原题，先自己说顺序，再展开

01氯苯、苄基氯、2-氯乙苯（2026 综合·鉴别）
  1. 加 AgNO₃ 乙醇溶液：苄基氯是苄卤，室温立即生成白色 AgCl ↓；氯苯与 2-氯乙苯不沉淀。
  2. 剩下两者加 酸性 KMnO₄ 加热：2-氯乙苯有乙基侧链（苄位有 H）被氧化，紫色褪去；氯苯无侧链，不褪色。
  3. 也可纯用活性序：苄基氯 > 2-氯乙苯 > 氯苯，靠 AgNO₃ 沉淀快慢三步分开。
02卤代烷的鉴别（2022）
  1. AgNO₃-乙醇法：烯丙型、苄基型、叔卤代烷室温迅速沉淀；仲卤代烷加热后沉淀；伯卤代烷更慢；乙烯型、芳基型不反应。
  2. 按 AgX 颜色分卤素：白 AgCl / 淡黄 AgBr / 黄 AgI。
  3. 辅助：NaI-丙酮法看沉淀速度（SN2 口径下 1° 最快），与 AgNO₃（SN1 口径 3° 最快）互为印证。
03伯、仲、叔醇（2023）
  1. Lucas 试剂（无水 ZnCl₂ + 浓 HCl）：叔醇立即浑浊分层；仲醇 5–10 min 浑浊；伯醇室温无变化。
  2. 辅助：酸性 K₂Cr₂O₇ 橙红变绿说明可被氧化（伯、仲醇），叔醇一般不变 —— 但单靠氧化法分不开伯仲，仍以 Lucas 为主。
04伯、仲、叔胺（2023 / 2021）
  1. Hinsberg 反应（苯磺酰氯 + 过量 NaOH）：伯胺生成的 N-取代苯磺酰胺 N 上还有 H，显酸性溶于碱，溶液澄清；仲胺产物 N 上无 H，不溶于碱，析出沉淀或油状物；叔胺不反应。
  2. 辅助 亚硝酸法：脂肪伯胺放 N₂；脂肪仲胺给黄色 N-亚硝胺油状物；脂肪叔胺无反应。芳香伯胺低温成重氮盐，加 β-萘酚偶联显红。
05苯甲酸、苯乙醇、苯乙酮（2023）
  1. 加 NaHCO₃：冒 CO₂ 气泡并溶解的是苯甲酸；另两者无反应。
  2. 剩下两者加 碘仿试剂（I₂/NaOH）：生成黄色 CHI₃ ↓ 的是苯乙酮（甲基酮）；无沉淀是苯乙醇。
06苯酚、醛、酮、羧酸（2022）
  1. NaHCO₃：出 CO₂ 的是羧酸。
  2. FeCl₃：显紫/蓝紫/绿色的是苯酚。
  3. Tollens 或 Fehling：银镜或砖红色沉淀的是醛，剩下是酮。
  4. 分不清羰基时先用 2,4-DNP 确认「有羰基」，再按上面分醛酮。顺序：酸 → 酚 → 醛 → 酮。
07葡萄糖、果糖、蔗糖（2021）
  1. Fehling / Benedict 加热：砖红色 Cu₂O 的是还原糖（葡萄糖、果糖）；不反应的是蔗糖。
  2. 对葡萄糖与果糖加 溴水（室温）：褪色的是醛糖（葡萄糖，醛基被氧化成羧酸），不褪的是酮糖（果糖）。
  3. 辅证 Seliwanoff：果糖显红快、葡萄糖慢。
08鉴别葡萄糖与果糖（2023 填空，答案要写具体试剂）

填 溴水。现象：葡萄糖使溴水褪色（醛糖被氧化成葡萄糖酸），果糖不褪色（酮糖不被溴水氧化）。

别只写「Fehling」—— Fehling 对两者都给阳性，分不开。

09末端炔烃的鉴别（2022 单选）

选 硝酸银氨溶液：炔氢弱酸性，生成白色炔化银 ↓。溴水、KMnO₄ 只能证明不饱和；氯化亚铜氨给的是砖红色炔化亚铜，不是白色；FeCl₃ 无此反应。

10结构推断通用套路（配 2021 真题的推断题形态）
  1. 算不饱和度：Ω = (2C + 2 + N − H − X) / 2。Ω≥4 先想苯环；Ω=1 想羰基或一个环/双键。
  2. 定性反应锁官能团：NaHCO₃→羧酸；FeCl₃→酚；Tollens→醛；碘仿→甲基酮；Br₂→不饱和；FeCl₃ 阴性但溶于 NaOH→可能是酚酯/内酯水解后显色。
  3. 拼装 + 回验：把碎片按「取代基位置/对称性」拼，再用 IR（3300 炔、1700 羰基、1600 芳环）与 ¹H-NMR（峰数=氢的环境数、积分=氢数、裂分=n+1）验一遍。
  4. 答题写「结构 + 每条证据对应哪个反应」，不要只写结构式。

四、易错与陷阱这些地方最容易掉分

1. Fehling 分不开醛糖/酮糖。果糖是酮糖但属还原糖，Fehling/Tollens 都给阳性。要分醛糖和酮糖只能用溴水或 Seliwanoff。

2. NaHCO₃ 是「酸 vs 酚」的分水岭。苯酚酸性太弱，不与 NaHCO₃ 出 CO₂；只能溶 NaOH 并用 FeCl₃ 显色。

3. AgNO₃ 法的活性顺序是 SN1 口径。写「苄基/烯丙基/叔 → 室温立即；仲 → 温热；伯 → 很慢；乙烯型/芳卤 → 不反应」最稳。NaI-丙酮是 SN2 口径（1° 最快），两者别混着写。

4. 2,4-DNP 只证明有羰基。醛、酮都沉淀，不能用来分醛酮，分醛酮必须 Tollens/Fehling。

5. Hinsberg 里「溶不溶」要说清对象。伯胺产物溶于过量 NaOH（N-H 显酸性）；仲胺产物不溶于碱；叔胺压根不反应。

6. 别漏「顺序」。鉴别题给分点一半在步骤：先加什么、看什么现象、剩下两者再加什么。只写试剂不写现象照样扣分。

五、考场答题格式照这个模板写，阅卷老师一眼能扫到

取少量样品，分别加入 ___ ，观察：

① 产生 ___ 现象者为 ___；② 无此现象者再分别加入 ___ ，产生 ___ 者为 ___；③ 余者为 ___。

三件套：试剂 + 现象 + 结论，一步一个分号，三步之内解决。写「加热/室温/0–5 ℃」这些条件是加分的。
